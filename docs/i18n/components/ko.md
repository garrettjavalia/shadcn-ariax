## 참고 사항

- Checkbox, Dropdown Menu, Input, Input Group, Kbd, Label, Message Scroller, Table, Textarea, Tooltip은 통합 또는 동작 관련 후속 검증이 남아 있습니다.
- Native Select: OS 네이티브 팝업은 검증 범위에서 제외합니다.
- Attachment: native trigger는 원본 동작을 유지하며 Dialog에 연결되어 있지 않습니다.
- Typography는 HTML 요소용 StyleX 레시피를 제공합니다.
- Toast는 업스트림에서 deprecated되었으므로 Sonner를 사용합니다.
